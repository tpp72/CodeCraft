# CodeCraft Studio

CodeCraft Studio is a modern web tool for generating and scanning **Barcodes and QR Codes** directly in your browser.

This project is built using **pure HTML, CSS, and JavaScript** without any frameworks.

## Features

- Generate **Barcode (CODE128)**
- Generate **QR Code**
- Download codes as **PNG images**
- Scan **Barcode or QR Code from uploaded images**
- Automatic detection using **ZXing**
- Modern UI with **Dark Theme / Light Theme**
- Clean responsive design

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [JsBarcode](https://github.com/lindell/JsBarcode)
- [QRCode.js](https://github.com/soldair/node-qrcode)
- [ZXing](https://github.com/zxing-js/library)

## How to Use

### 1. Generate Barcode

1. Open **Barcode Generator**
2. Enter the text or product code
3. Click **Generate Barcode**
4. Click **Download PNG**

### 2. Generate QR Code

1. Open **QR Code Generator**
2. Enter text or URL
3. Click **Generate QR Code**
4. Download the image

### 3. Scan Code from Image

1. Go to **Scanner**
2. Upload an image containing a Barcode or QR Code
3. Click **Scan Image**
4. The decoded result will appear automatically
